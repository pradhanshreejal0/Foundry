# Foundry Multi-Vendor E-Commerce Platform

A high-performance, premium multi-vendor e-commerce platform built with the MERN stack (MongoDB, Express, React, Node.js) and Tailwind CSS v4, featuring a luxurious **Dark & Gold** aesthetic.

---

## Getting Started

You can run this project using either **npm** or **pnpm**.

### 1. Installation

**Using npm:**
```bash
npm run install:all
```

**Using pnpm:**
```bash
pnpm install:all
```

### 2. Running Development Servers

Both frontend and backend can be run concurrently with a single command:

**Using npm:**
```bash
npm run dev
```

**Using pnpm:**
```bash
npm run dev:pnpm
```

---

## Project Structure

- `server/` — Node.js + Express API backend & Mongoose models
- `client/` — Vite + React frontend with Tailwind CSS v4 & Lucide icons
- `docs/` — Architecture specs and implementation design docs
